# Game_Zone — 3D Cyber Arena & Esports Tournament Platform

An immersive, blockbuster WebGL/Three.js 3D esports arena with dynamic camera spline flight paths, interactive game cards, cinematic seismic rift opening, and team registration system.

## 🚀 Key Features

- **Cinematic Seismic Intro**: Camera rumble, cracking earth with glowing laser conduits, multi-strike lightning flashes, and 3D gateway pillars & earth globe emerging upwards from subterranean depths.
- **Interactive 3D Game Battlefields**: 5 featured tournament titles (Tekken 8, Mortal Kombat 1, FIFA 26, Call of Duty Mobile, BGMI) with 3D tilt physics, golden frames, cyber holographic badges, and floating sparks.
- **Smooth Spline Camera Navigation**: Mouse parallax, keyboard shortcuts, wheel & touch support.
- **Registration & Admin Suite**: Registration drawer and Supabase database integration.
- **Cyber Audio Synthesizer**: Web Audio API ambient hum, seismic rumble, warp transitions, and lightning crackles.

## 🛠️ Tech Stack

- **Framework**: Next.js (App Router, Turbopack)
- **3D Graphics**: Three.js, React Three Fiber, React Three Drei
- **Animation**: Framer Motion
- **Styling**: Tailwind CSS
- **Database**: Supabase
- **Icons**: Lucide React

## 🏁 Getting Started

First, install dependencies:

```bash
npm install
```

Set up your `.env.local` based on `.env.example`:

```bash
cp .env.example .env.local
```

Run the development server:

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
